# Infoeb3.0
Быстрый и легковесный консольный инструмент на Python для анализа истории сообщений из Telegram-чатов. Программа работает локально, не требует установки сторонних библиотек и парсит экспортированный JSON-файл за доли секунды.

Возможности проекта

Программа предоставляет интерактивное меню со следующими функциями:

Первое сообщение — показывает автора, дату и текст самого первого сообщения в чате.

Счетчик сообщений — выводит общее количество реплик.

Возраст чата — высчитывает точный интервал времени, сколько существует чат.

Топ говорунов — формирует рейтинг самых активных участников.

Популярные темы — выводит топ-20 самых обсуждаемых тем

Сиксеевен — супер секретная функция

Поиск слова — мгновенно находит, сколько раз конкретное слово встречалось в переписке (без учета регистра).

Общий объем — считает все слова в чате

Статистика по годам — разбивает активность чата по временным периодам.
